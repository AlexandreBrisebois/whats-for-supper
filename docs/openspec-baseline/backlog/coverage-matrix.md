## Exclusions challenged and consolidated

- **Feature Flags:** broad missing-feature concern disproved by independent 12/28 mapping and13 passing focused assertions. Keep ownership under member-preferences; no duplicate extraction.
- **Dreaming:** actual pruning, backup launch, maintenance commands, overdue, reconciliation, materialization, report and recurrence all traced. Composition already covered; missing materializer business output extracted under recipe-search. Launch success does not establish child completion.
- **Tonight:** existing changed-plan requirements do not settle correctness. User now requires Tomorrow push into following weeks and deployment-local dates; existing UTC/empty-slot source baseline is not accepted desired behavior.
- **Stack:** user-reported wrong final recipe remains unresolved for actual dataset; controlled probe shows incorrect ordinal/sparse traversal. Existing180-ID browser assertion is affirmative counter-evidence to a universal26-card cap.
- **Cooking fallback:** reachable generic steps on load failure cannot remain invisible as an exclusion; WFS-BL-014 is recovery policy/defect work, not a normative fallback draft.
- **Intended but absent / placeholders:** fixed recommendations, unhandled discovery_nudge, unused search filters and offline application cache are not extracted as implemented capabilities. Product decision/retirement remains026/024. Unmounted LocaleToggle is not a separate current ordinary journey; connected Settings language owns it.
- **Shared behavior:** auth/identity under household-identity; dispatch/retry under background-processing; raw live transport under household-live-updates; schedule dates under meal-planning; backup child acceptance under data-backup-and-recovery. Cross-owner consumers link these instead of duplicating guarantees.
