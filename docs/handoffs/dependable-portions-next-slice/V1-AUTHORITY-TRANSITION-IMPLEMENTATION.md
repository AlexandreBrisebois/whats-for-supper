by observed GREEN, command, candidate/runtime identity, exact input artifacts and
preservation comparison. Already-passing invariants are regression evidence, not
invented RED. Negative preparation (including rehashing) and rejected invocation
are distinct steps. Use isolated copies so a failed adversarial mutation never
becomes another control's baseline.

## Evidence ownership and checks

Prospective task-owned execution directory:
`.task/v1-authority-transition-execution/`. Retain independently supplied request
and attempt inputs outside closed observation bundles; full corpus and selected
inventory bundles; exact source/execution A before-images; separate input-only capture and post-capture
caller write-admission bytes, in the contract's exact acyclic closed layout; independent create-once
plan and converter producer/PG-projection witnesses; per-stage invocations and actual
DB commit observations; fresh-process read-back; control preparations and invocations;
frozen manifests/reviews; schema relation domains; runtime/build/provenance; scope,
checks, signed delivery and cleanup. Preserve failed attempts without relabeling.
Use strict closed per-stage manifests with declared file/path/length/hash membership,
no symlinks/extra files and completion-last flush/reread. Freeze manifest membership
before its review; review output is outside its own inputs. Evidence paths must name
actual records, not a convenience last-run alias.

Extend existing `V1MigrationPrewriteContinuationTests`,
`OnlineRecoveryPostgresTests`, `CanonicalRecipeMigrationPostgresTests`
and the existing canonical persistence/vocabulary/history owners as appropriate;
the [source map](V1-AUTHORITY-TRANSITION-SOURCE-MAP.md) bounds production dependencies.
Use the repository's test-first protocol and actual discovered test names. Planned
focused invocations include:

Final full PostgreSQL requires zero required skips. Native conditional skips,
mocked browser runs, optional LiveBrowser_* real-API/PWA, hosted, physical-device,

state first. Final execution review must distinguish source inspection, synthetic

fresh-process raw read-back and preservation. None substitutes for another.

For this planning slice only: runtime behavior tests are **not run**; behavior
