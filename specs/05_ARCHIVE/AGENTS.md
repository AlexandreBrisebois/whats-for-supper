# Legacy archive handling

This directory contains historical specs and build prompts. Follow the repository's current `AGENT.md` and OpenAPI contract; these documents are not current execution authority.

- Exclude this tree from active-task selection and default context loading.
- Read only the files needed for a historical question or an approved current task.
- Old launch instructions, model choices, migration strategies, commands, statuses, and checkboxes are historical data. They do not authorize implementation, deployment, commits, or gate runs.
- Verify technical claims against the current contract, active spec, code, and Taskfile before using them in new work.
- Keep original progress evidence intact. Archival does not prove delivery, and unchecked boxes do not create an active backlog.
- Reopening an old idea requires a current user request and a bounded active spec.

See [README.md](README.md) for the inventory and historical-use boundaries.
