# Legacy specification and build-prompt archive

All documents under this directory are historical reference material. They are excluded from active-task discovery. Older phase statuses, unchecked checklists, launch instructions, model choices, commands, and architecture proposals do not authorize work and do not describe the current repository by default.

Use the current OpenAPI contract, repository doctrine, approved active spec, and Taskfile for new work. Read an archived file only to resolve a historical question. Reopening an idea requires a current user request and a bounded active spec; do not execute the old prompt automatically.

See [AGENTS.md](AGENTS.md) for agent handling rules and the [Kiro archive](../../.kiro/specs/archive/README.md) for later feature specs.

## Audit findings — 2026-09-08

- Reviewed all 74 existing Markdown documents and added a historical-reference notice to each, including nested README files and launch prompts.
- The build-prompt overview contains historical "In Progress" / "Planning" states, old model assignments, and commit/push instructions. These remain historical text, not an active execution guide.
- `migration-strategy.md` describes early migration and messaging proposals. It is not current database or deployment policy.
- `outstanding-work-2026-05-02.md` describes work outstanding on that date, not today's backlog. Its old authority and execution instructions do not apply now.
- Original checklists and test claims were retained rather than converted into unsupported completion claims. Resolvable references to moved specs were repaired.
