# Gemini CLI / Antigravity mechanics

Use [AGENT.md](../../AGENT.md) as the shared protocol. `GEMINI.md` is the
repository route for Gemini CLI and Gemini-based Antigravity sessions. These are
distinct hosts: record the actual host, model and exposed settings when probing
loading; a CLI result does not qualify Antigravity.

Use the active host's available tools, workspace controls and native permission
mechanisms. Repository precedence does not override platform/system constraints.
Use native delegation only when exposed, following shared context and ownership
policy; otherwise work sequentially. Do not infer capabilities or required
procedures from a model brand or size. Verify automatic file loading in a fresh
session instead of assuming it from filenames.
