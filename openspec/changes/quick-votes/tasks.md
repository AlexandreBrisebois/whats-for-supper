# Tasks

No OpenAPI, backend controller, or database migration changes. Backend persistence reuses the existing `GET /api/settings/{key}` and `POST /api/settings/{key}` endpoints (`api/src/RecipeApi/Controllers/SettingsController.cs`, `api/src/RecipeApi/Services/SettingsService.cs`, `specs/openapi.yaml`) and the generated Kiota client (`pwa/src/lib/api/generated/api/settings/`).
