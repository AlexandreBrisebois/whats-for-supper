# Proposal

## Why

Main recipe-library describes list visibility and detail reading but leaves the connected detail editor undocumented. Extract its current ordinary-household behavior into a bounded baseline, with source support distinguished from runtime qualification.

## What Changes

- Add detail-editing requirements for opening initialized drafts, supported fields, local Save eligibility, normalized submission, server partial-update semantics, pending feedback, Cancel, successful local completion and failure recovery.
- Record cuisine clearing, response-contract, post-commit failure and assertion limitations without repairs or unsupported guarantees.
- Update the durable plan with evidence and scenario mappings; stop with a validated draft for review.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `recipe-library`: add only missing detail-editing behavior after successful detail loading; preserve its Purpose and all 16 existing requirements/31 scenarios. Reuse household-identity access/member context and existing library fact/read ownership.

## Impact

Documentation only: this change's metadata, proposal, recipe-library delta, extraction design/tasks and `docs/openspec-baseline-plan.md`. Evidence follows the connected library caller through RecipeDetailSheet, adapter/generated PATCH, OpenAPI, controller/service, EF save, indexing attempt, recipe.info write and local completion. No application, tests, contract, generated client or SQL changes; no services, mutations or database access.

Ratings/notes submission, reporting/re-import, sharing, original-photo browsing, hero generation, cooking mode/instruction editing, planning, ranking, capture, deletion/restore/purge, preferences and demo/preview/deployment variants are excluded. Acceptance, promotion, archival and successor extraction need separate authorization. A10 permits source-supported extraction; A34 defers runtime/database qualification. No unresolved intent choice is needed for the supported assertions; discrepancies remain non-normative under A12 and the present instruction.
