# Proposal

## Why

Executable startup and operator workflows produce search vocabulary, index documents and vegetarian facts, while the baseline mainly describes their consumers. This documentation-only extraction closes supported omissions previously deferred by SR-U10/SR-X03 without claiming runtime qualification.

## What Changes

- Add source-supported materialization and index-publication requirements under recipe-search.
- Add operator vegetarian classification, bounded backfill and metrics under recipe-library.
- Preserve shared workflow scheduling/retry ownership and existing Dreaming composition under data-backup-and-recovery.
- Record source and assertion evidence, including substituted boundaries; leave disputed reliability guarantees non-normative.
- Withhold the existing UTC recency calendar reference pending WFS-BL-005. The settled policy is deployment-fixed local UX dates, UTC internal timestamps and injected clocks; this draft does not claim implementation compliance.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `recipe-search`: producer behavior for materialized filters and published search documents.
- `recipe-library`: operator production and observation of persisted vegetarian facts.

## Impact

Only this new change's documentation is edited. No application, tests, contract, configuration, SQL or main specifications change. No provider calls, destructive operations, acceptance, promotion or archival are authorized by these artifacts. Human review remains pending. Sources and exact assertion mappings are in design.md; desired fixes are separate backlog work.
