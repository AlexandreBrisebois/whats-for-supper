# Proposal

## Why

Tonight presentation and immediate choices have no dedicated baseline draft. Extract the existing ordinary-household Home journey while referencing accepted planning and live-update policy.

## What Changes

- Document planned, cooked, empty and Mystery-night presentation and Home Quick Find assignment.
- Reference existing non-cooking edit and shared Quick Find requirements instead of duplicating them.
- Record source evidence, assertion substitutions and uncertain recovery/freshness boundaries in the capability plan.

## Capabilities

### New Capabilities

- `tonight-meal-decisions`: Home presentation and immediate supper choice, consuming shared planning operations.

### Modified Capabilities

None.

## Impact

Documentation extraction only. Read boundaries: HomePage, TodayStoreInitializer, HomeCommandCenter, TonightPivotCard, todayStore, QuickFindModal, schedule SDK/OpenAPI and ScheduleController/Service. No application, tests, contracts, configuration or main specs change. TM-G01 authorizes the complete capability draft sequence; acceptance, promotion, archival and runtime qualification remain outside scope. Evidence: BSL-tonight-meal-decisions-001–004 and 010 in docs/openspec-baseline/tonight-meal-decisions.md.
