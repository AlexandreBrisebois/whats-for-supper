# Proposal

## Why

The promoted recipe-capture baseline covers URL and photo entry but leaves description entry undocumented. Extract its existing ordinary-household journey with explicit evidence limits so successful intake is not mistaken for successful generation or recovery.

## What Changes

- Add description-specific entry, required name and optional description, advisory duplicate lookup, submission, initial recipe creation and background synthesis behavior to `recipe-capture`.
- Reuse existing readiness, inline completion, countdown and session-bound failure presentation requirements; document description-specific connections and unresolved contract/recovery discrepancies in design and evidence.
- Record source identities, actual test assertions and substitutions, mappings and deferred A34 qualification in the durable baseline plan.
- Produce documentation-extraction tasks only; preserve promoted URL/photo requirements verbatim.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `recipe-capture`: Extend the baseline with description entry and synthesis-specific behavior, without changing existing URL/photo requirements.

## Impact

Documentation only: this proposal, recipe-capture delta, extraction design/tasks and `docs/openspec-baseline-plan.md`. Affected evidence spans the capture component, generated describe client/OpenAPI, controller/service, synthesis workflow/agent, persistence, ready/failure notifications and their tests. No code, tests, contracts, generated clients, SQL, dependencies or configuration changes; no services or runtime/database qualification.

PDF, photo/URL changes, manual editing, hero-image generation behavior, planning and demo/preview variants are excluded. GOTO settings are a caller dependency outside this ordinary capture slice. Exact submission success status is disputed (controller/tests 200 versus OpenAPI 202); the draft withholds that numeric guarantee by the user’s confirmed decision. Workflow launch and model completeness are not guaranteed by intake success; failed synthesis recovery is incomplete. Human acceptance, promotion, archival and implementation remain separate and unauthorized.
