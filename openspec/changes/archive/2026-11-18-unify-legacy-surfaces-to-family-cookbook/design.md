## Decisions and Tradeoffs

### 1. Entry, Shell, Shared UI & Global Notifications (Wave A)

- **Welcome / Landing / Onboarding:** Replace `text-indigo`/`bg-indigo`/`text-lavender`/`bg-ochre text-white` with Family Cookbook tokens (`font-heading text-charcoal`, `<Button variant="primary" size="lg">`, `text-terracotta-700` alerts, `bg-cream`).
- **Navigation (`Navigation.tsx`):** Move `NAV_ITEMS` localization inside the render path using `useLocale()` so locale toggles update tab labels cleanly without reload; raise tab label size to `text-xs` (`12px`) sentence case, inactive color to `text-charcoal-600`, and `min-h-12` targets. Lock the Discover orb to `h-16 w-16` (`64px`, `-top-3`) with tonal sunlit styling (`bg-ochre-100 text-ochre-800 border border-ochre-300 ring-4 ring-cream-100` at `7.32:1` + `text-ochre-800` label at `7.67:1` on cream), preserving `Layout.tsx`'s `96px` bottom clearance and `320px` French reflow (`Accueil | Recettes | Découverte | Plan | Profil`), keeping `pulse-ochre` only when voting is actively `collecting`.
- **Header (`Header.tsx`):** Strip the dead `getGreeting()` / `useFamilyStore` greeting fallback and unused `Sparkles` import so `Header` renders `title` when provided and the `Supper` brand link otherwise, adding zero unused greeting locale keys.
- **Shared `SuccessCard.tsx` (Option A Deep Herb):** Upgrade `SuccessCard.tsx` to Deep Herb (`bg-gradient-to-br from-sage-600 to-sage-700`, `text-white` title, `text-cream-100` subtitle, `bg-white text-sage-700 border-sage-200 text-xs font-semibold min-h-12` action button, matching Board 03) across both Discovery (_"Menu's in!"_) and Home (_"Enjoy your meal!"_) while preserving Home's existing cooked copy and dismiss behavior.
- **Global Notifications & Shared Spinner (`LanguageSwitchProposal.tsx`, `RecipeFailureBanner.tsx`, `spinner.tsx`, `loading.tsx`):** Migrate `LanguageSwitchProposal.tsx` to `bg-sage-700 text-white` (`7.22:1`), `text-sage-700`, `text-charcoal-600`, and `>= 48px` targets; update `RecipeFailureBanner.tsx` dismiss/retry controls to `>= 48px` with `text-charcoal-600` close icon; replace `border-indigo` in `spinner.tsx` with `border-terracotta` and `text-charcoal-400` in `common/loading.tsx` with `text-charcoal-600`.

### 2. Making _"Swipe, Match, Cook!"_ Richer & Clearer for Families (Wave B)

- **`DiscoveryCard.tsx` (`line-clamp-2` description & on-photo `Ready in` pill):** Render `description?.trim()` in `text-sm font-medium text-charcoal-600 line-clamp-2` beneath the `font-heading text-2xl font-bold text-charcoal` recipe title, omitting the element completely when `description` is empty/whitespace. Reduce `h-[62%]` hero image proportionally (`h-[58%]`) on tall cards only when description is present, preserving image dominance and zero cuisine/meal-type pill clutter (`recipe-discovery` spec constraint). Switch the photo-overlaid `Ready in` pill from `bg-terracotta-50 text-terracotta-700` to solid warm cream `bg-cream text-charcoal` (`15.08:1`, dropping forced CSS `uppercase` while keeping the `common.readyIn` locale string untouched) to match Layer 2 / Board 04 on-photo pills.
- **Voting Overlays & Controls:** Replace `bg-sage/30` (`LOVE` overlay) with `bg-sage-700/90 text-white` for crisp legibility over bright photography; change `Just planned ✓` badge to `bg-sage-50 border-sage-200 text-sage-800`; switch Like/Dislike thumb-zone buttons from bare `text-sage` / `text-terracotta` to `text-sage-700` / `text-terracotta-700`; change empty-state primary CTA and `FamilyNudgeDialog` Share button from `bg-ochre text-white` to `bg-terracotta text-cream-100`.

### 3. Retiring `QuickFindModal` 3D Flip & Unifying Planner/Capture Sheets (Wave C)

- **Inline Disclosure in `QuickFindModal.tsx`:** Replace the `perspective-1000` / `rotate-y-180` / `backface-hidden` two-sided card flip with a scrollable Family Cookbook card (matching `TonightMenuCard` and `DiscoveryCard` proportions) featuring an explicit `min-h-12` button (`View details` / `Hide details` with `aria-expanded` and `ChevronDown`) that expands `description` and `ingredients` inline while keeping the recipe photo, title, and `Select` / `Use for this night` button visible and immediately actionable.
- **Home Cleanup (`HomeSections.tsx`, `HomeGreeting.tsx`):** Move `VotingNudgeCard` onto a sunlit `bg-ochre-50 border border-ochre-200` card with a `bg-ochre-100 text-ochre-800` `Vote` badge and a crisp `bg-white text-ochre-800 border border-ochre-300 hover:bg-ochre-100 shadow-sm` CTA (`7.91:1`), eliminating `bg-ochre text-charcoal` while keeping Tonight's primary terracotta CTA visually dominant. Verify `HomeGreeting.tsx` has zero remaining imports across the repo and delete it rather than localizing dead code (if an active importer unexpectedly exists at apply time, fix and localize it instead).
- **Browse Card Parity (`RecipeStackCard.tsx`):** Mirror the solid `bg-cream text-charcoal` on-photo `Ready in` pill from `DiscoveryCard.tsx` (dropping forced CSS `uppercase` while keeping `common.readyIn` copy untouched) and raise swipe feedback overlays (`bg-sage/30`, `bg-terracotta/30`) so Browse Stack and Discovery stay visually unified.
- **Planner Participation Buttons & Micro-Text:** Upgrade `Ask the Family` and `Nudge family` in `planner/page.tsx` from `bg-sage text-[9px] text-white` to Option A Deep Herb `bg-sage-700 text-xs font-semibold text-white` (`7.22:1`, sentence case, `min-h-12`, matching Board 03), switch `.solar-earth-bg` -> `.cookbook-bg`, and upgrade remaining `9px`–`11px` labels across `planner`, `PlanningPivotSheet`, `SkipRecoveryDialog`, and `MinimalCapture` to `>= 12px` sentence case.

### 4. Settings, Recycle Bin & Ratchet Closure (Wave D)

- Replace `red-50/100/200/500/600/700` in `RecycleBinSheet.tsx` with `terracotta-50`/`terracotta-200`/`terracotta-700` destructive pairings (`>= 48px` Restore, Delete, Cancel, and Close buttons).
- Raise `FailedCapturesSection` clear button to `h-12 w-12` (`48px`) and Retry to `min-h-12` `text-xs`.
- Remove every entry from `LEGACY_ERA_ALLOWLIST` in `pwa/src/test/visual-contract.test.ts` so `visual-contract.test.ts` enforces 100% app-wide compliance, then recapture `docs/screenshots/demo-*.png` from the live Demo state.

## Compatibility, Rollout and Reversal

- **Apply Sequencing:** Apply `refine-mobile-planner-recipes-and-grocery-ux` first so Wave A (`Navigation.tsx`) and Wave C (`MinimalCapture.tsx`, `planner/page.tsx`, `GroceryList.tsx`, `RecipeDetailSheet.tsx`, `RecipesExperience.tsx`) land cleanly on top of refined UX without rework.
- **Test IDs and `aria-label` contracts preserved:** Retain all `data-testid`s (`discovery-card`, `like-button`, `dislike-button`, `quick-find-modal`, `recovery-dialog-title`, `action-restore-*`, `action-purge-*`, etc.) and semantic accessibility labels; update only unit/E2E assertions explicitly expecting removed 3D-flip behavior, missing `description`, or legacy red/ochre/sage classes.
- **Locale completeness:** Any newly extracted strings (`MinimalCapture`, `QuickFindModal`, `SkipRecoveryDialog`, etc.) add matching EN and FR keys verified by `locale-integrity.test.ts`; do not add unused greeting keys for retired `Header` / `HomeGreeting` paths.

## User Experience

- **For kids & family during Voting:** Seeing a brief 1–2 line appetizing description beneath each dish photo makes _"Swipe, Match, Cook!"_ meaningful even when recipes have shorthand family names.
- **For tired cooks in Quick Find & Recovery:** Replacing the disorienting 3D card flip and `"RECOVERY FLOW"` micro-chrome with inline cookbook disclosure and calm sentence-case choices lowers cognitive strain at 5:00 PM.
- **For the whole app:** Emptying `LEGACY_ERA_ALLOWLIST` ensures no forgotten screen (`InviteLinkDialog`, `RecycleBinSheet`, `SubmitConfirmation`, `error.tsx`) breaks the warm Family Cookbook feel.
